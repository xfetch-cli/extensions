<div align="center">
  <h1>Theme Sync Extension</h1>
  <p>Applies the active equisdots palette to xfetch at runtime.</p>
</div>

<br>

<div align="center">
  <table>
    <tr>
      <td><strong>Kind</strong></td>
      <td><code>config_provider</code></td>
    </tr>
    <tr>
      <td><strong>Artifact</strong></td>
      <td><code>theme-sync.wasm</code> (core module)</td>
    </tr>
    <tr>
      <td><strong>Runtime</strong></td>
      <td><code>wasm32-wasip1</code></td>
    </tr>
    <tr>
      <td><strong>Capabilities</strong></td>
      <td>read-only <code>~/.config</code>, <code>HOME</code></td>
    </tr>
  </table>
</div>

<br>

<h2>Install</h2>

<pre><code>xfetch extension install theme-sync</code></pre>

<h2>Configuration</h2>

<pre><code class="language-jsonc">{
  "config_providers": [
    {
      "extension": "theme-sync",
      "args": {
        "settings": "~/.config/hypr/settings.json",
        "themes_dir": "~/.config/xfetch/themes",
        "fallback": "x"
      },
      "timeout_secs": 3
    }
  ]
}</code></pre>

<h3>Args</h3>

<table>
  <thead>
    <tr><th>Field</th><th>Type</th><th>Default</th><th>Description</th></tr>
  </thead>
  <tbody>
    <tr>
      <td><code>settings</code></td>
      <td>string</td>
      <td><code>~/.config/hypr/settings.json</code></td>
      <td>equisdots settings file; reads <code>bar.palette</code> and the legacy <code>dock.palette</code>.</td>
    </tr>
    <tr>
      <td><code>themes_dir</code></td>
      <td>string</td>
      <td><code>~/.config/xfetch/themes</code></td>
      <td>Directory containing <code>&lt;slug&gt;.jsonc</code> themes.</td>
    </tr>
    <tr>
      <td><code>fallback</code></td>
      <td>string</td>
      <td><code>x</code></td>
      <td>Palette slug used when the settings file is missing or has no palette.</td>
    </tr>
    <tr>
      <td><code>force</code></td>
      <td>bool</td>
      <td><code>false</code></td>
      <td>Apply the palette even when the config already has non-empty <code>colors</code>, and override <code>logo_color</code>.</td>
    </tr>
  </tbody>
</table>

<p>
  The extension is a no-op when the config already has a non-empty
  <code>colors</code> object unless <code>force</code> is set. This is
  deliberate: after <code>config-roulette</code> selects a route config
  without colors, theme-sync restores the active palette at runtime.
</p>

<p>
  The theme files are generated by equisdots/theme-sync
  (<code>theme-sync.sh --targets xfetch</code>). This extension only reads
  them; it does not generate themes. Both paths must live under
  <code>~/.config</code>, which is the only filesystem mount the extension is
  granted.
</p>

<h2>Build</h2>

<pre><code>rustup target add wasm32-wasip1
cargo build --release --target wasm32-wasip1 -p xfetch-extension-theme-sync
mkdir -p extensions/theme-sync/dist
cp target/wasm32-wasip1/release/xfetch-extension-theme-sync.wasm \
  extensions/theme-sync/dist/theme-sync.wasm</code></pre>

<p>
  A prebuilt <code>dist/theme-sync.wasm</code> is checked in, so installing
  from the catalog does not require a Rust toolchain.
</p>
